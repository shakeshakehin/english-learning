# wordDB · 生词表

> 用法：阅读时遇到生词，在下面表格**加一行**（单词 | 中文释义），保存后运行 vault 根目录的 `deploy.sh` 同步到网站，网页文章里包含这些词会自动高亮。
> 规则：单词小写；释义用中文；重复词不要加第二行（脚本自动去重）。

| 单词 | 释义 |
|------|------|
| catalyst | 催化剂；触发因素 |
| pivotal | 关键的，核心的 |
| streamline | 精简，使效率化 |
| regression | 回归（测试） |
| assertion | 断言 |
| flaky | 不稳定的（测试） |
